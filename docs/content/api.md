@page TrustLiMe_api C++ API reference

This page lists the classes and free functions of the TRUST-LiMe module and
links to their generated reference pages. The complete reference (including
every inherited TRUST kernel member, the source browser and the call graphs)
is generated by Doxygen from `src/`: use the *Class List* entry of the
navigation tree, or the links below, for the module's own classes.

The module deliberately reuses as much of the TRUST kernel as possible: every
class below derives from a kernel base class (linked from each reference
page's inheritance graph), and only the magnetic-specific hooks are
overridden.

## Problems and equations

- @ref Pb_MHD "Pb_MHD" — the magnetic problem: one Convection_Diffusion_Magnetic_field
  equation, optionally followed by extra equations (e.g. Navier-Stokes for the
  coupled low-Rm mode). See @ref TrustLiMe_model "the model page".
- @ref Convection_Diffusion_Magnetic_field "Convection_Diffusion_Magnetic_field" —
  the magnetic induction equation
  \f$ \partial_t b + (u\cdot\nabla) b - \nabla\cdot(\eta \nabla b) = S \f$,
  its keywords (`diffusivite_magnetique`, `vitesse_magnetique`, `mu0`,
  `rapport_charge_masse`, `nb_composantes`) and its post-treatment fields.

## Boundary condition

- @ref Paroi_isolante_magnetique "Paroi_isolante_magnetique" —
  `paroi_isolante_magnetique`: perfectly insulating magnetic wall
  (homogeneous Neumann on every component).

## Source terms

- @ref Terme_Source_Induction_stretching "Terme_Source_Induction_stretching" —
  `induction_stretching`: the M1 source term \f$ S = (b\cdot\nabla) u \f$ for
  a given, frozen transporting velocity.
- @ref Terme_Source_Lorentz "Terme_Source_Lorentz" —
  `force_lorentz`: the Lorentz force density \f$ J \times B \f$ applied to the
  momentum equation of a Pb_MHD problem (coupled low-Rm mode).

## Post-treatment fields

- @ref Champ_Fonc_MHD "Champ_Fonc_MHD" — the element field class that serves
  every derived quantity by name (`energie_magnetique`, `vecteur_poynting`,
  `tension_magnetique`, ...) through the equation's
  Convection_Diffusion_Magnetic_field::creer_champ() hook. See the
  *Post-treatment fields* section of @ref TrustLiMe_model "the model page".

## Arithmetic kernels (header-only)

Physics conventions kept directly unit-testable, free of any TRUST framework
dependency (see @ref TrustLiMe_testcases "the unit-test description"):

- `mhd_*` functions of `MHD_posttraitement_kernel.h` — the formulas of all
  post-treatment fields (energy, Poynting, helicities, curl/divergence of b,
  Lorentz force, dimensionless numbers).
- `induction_stretching_ajouter()` of `Induction_stretching_kernel.h` — the
  \f$ (b\cdot\nabla) u \f$ contraction and its index convention.
