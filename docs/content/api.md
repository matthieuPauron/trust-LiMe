@page TrustLiMe_api C++ API reference

This page lists the classes and free functions of the TRUST-LiMe module and
links to their generated reference pages. The complete reference (including
every inherited TRUST kernel member, the source browser and the call graphs)
is generated by Doxygen from `src/`: use the *Class List* entry of the
navigation tree, or the links below, for the module's own classes.

The module deliberately reuses as much of the TRUST kernel as possible: every
class below derives from a kernel base class (linked from each reference
page's inheritance graph), and only the magnetic-specific hooks are
overridden.

## Problems and equations

The three problem classes share one equation and differ only in which momentum
equation (if any) is solved alongside it — the same split the kernel uses for
`Pb_Conduction` / `Pb_Thermohydraulique` / `Pb_Thermohydraulique_Turbulent`:

| Problem | Base class | Equations (in order) |
|---|---|---|
| @ref Pb_Induction "Pb_Induction" | `Probleme_base` | magnetic only (prescribed velocity) |
| @ref Pb_MHD "Pb_MHD" | `Pb_Hydraulique` | `Navier_Stokes_std`, then magnetic |
| @ref Pb_MHD_Turbulent "Pb_MHD_Turbulent" | `Pb_Hydraulique_Turbulent` | `Navier_Stokes_turbulent` (k-eps), then magnetic |
| @ref Pb_MHD_Thermal "Pb_MHD_Thermal" | `Pb_Thermohydraulique` | `Navier_Stokes_std`, then energy, then magnetic |

- @ref Pb_Induction "Pb_Induction" — the induction-only problem: a single
  Convection_Diffusion_Magnetic_field equation advected by a prescribed
  velocity. It derives from `Probleme_base`, not `Pb_Fluide_base`, because it
  has no momentum equation to expose at index 0.
- @ref Pb_MHD "Pb_MHD" — hydro + induction with a laminar momentum equation.
  The momentum equation is at index 0 and the magnetic one at index 1, which
  is the order the data file must use.
- @ref Pb_MHD_Turbulent "Pb_MHD_Turbulent" — the same layout with
  `Navier_Stokes_turbulent`; the hydraulic k-eps model is reused for the
  magnetic turbulent diffusivity.
- @ref Pb_MHD_Thermal "Pb_MHD_Thermal" — hydro + thermal + magnetic, with the
  energy equation at index 1 and the magnetic equation at index 2 (momentum
  stays at index 0).
- @ref Convection_Diffusion_Magnetic_field "Convection_Diffusion_Magnetic_field" —
  the magnetic induction equation
  \f$ \partial_t b + (u\cdot\nabla) b - \nabla\cdot(\eta \nabla b) = S \f$,
  its keywords (`diffusivite_magnetique`, `vitesse_magnetique`,
  `vitesse_hydraulique`, `mu0`, `rapport_charge_masse`, `nb_composantes`,
  `couplage_fort`) and its post-treatment fields.

## Boundary condition

- @ref Paroi_isolante_magnetique "Paroi_isolante_magnetique" —
  `paroi_isolante_magnetique`: perfectly insulating magnetic wall
  (homogeneous Neumann on every component).

## Source terms

- @ref Terme_Source_Induction_stretching "Terme_Source_Induction_stretching" —
  `induction_stretching`: the M1 source term \f$ S = (b\cdot\nabla) u \f$ for
  a given, frozen transporting velocity.
- @ref Terme_Source_Lorentz "Terme_Source_Lorentz" —
  `force_lorentz`: the Lorentz force density \f$ J \times B \f$ applied to the
  momentum equation of a Pb_MHD / Pb_MHD_Turbulent problem (coupled low-Rm
  mode).

## Independent magnetic k-ε closure (Phase 3, in source)

- @ref Modele_turbulence_magnetique "Modele_turbulence_magnetique" —
  `modele_turbulence_magnetique`: owns the closure coefficients, the
  Alfvén-normalized k_b / epsilon_b fields and the derived `eta_t`.
- @ref Convection_Diffusion_K_Magnetic "Convection_Diffusion_K_Magnetic" —
  transport equation for k_b.
- @ref Convection_Diffusion_Epsilon_Magnetic "Convection_Diffusion_Epsilon_Magnetic" —
  transport equation for epsilon_b.
- @ref Terme_Source_K_Magnetic "Terme_Source_K_Magnetic" — k_b source
  (production \f$P_b\f$ minus dissipation).
- @ref Terme_Source_Epsilon_Magnetic "Terme_Source_Epsilon_Magnetic" —
  epsilon_b source (\f$C_{\epsilon 1b}(\epsilon_b/k_b)P_b -
  C_{\epsilon 2b}\epsilon_b^2/k_b\f$).

## Post-treatment fields

- @ref Champ_Fonc_MHD "Champ_Fonc_MHD" — the element field class that serves
  every derived quantity by name (`energie_magnetique`, `vecteur_poynting`,
  `tension_magnetique`, ...) through the equation's
  Convection_Diffusion_Magnetic_field::creer_champ() hook. See the
  *Post-treatment fields* section of @ref TrustLiMe_model "the model page".

## Arithmetic kernels (header-only)

Physics conventions kept directly unit-testable, free of any TRUST framework
dependency (see @ref TrustLiMe_testcases "the unit-test description"):

- `mhd_*` functions of `MHD_posttraitement_kernel.h` — the formulas of all
  post-treatment fields (energy, Poynting, helicities, curl/divergence of b,
  Lorentz force, dimensionless numbers).
- `induction_stretching_ajouter()` of `Induction_stretching_kernel.h` — the
  \f$ (b\cdot\nabla) u \f$ contraction and its index convention.
