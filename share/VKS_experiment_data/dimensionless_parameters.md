# Dimensionless parameters

Source papers: `Bourgoin2002`, `Monchaux2009`.

## Definitions

| Symbol | Definition | Source |
|---|---|---|
| Rm | K mu0 sigma 2 pi R_c^2 F | Monchaux2009 |
| Re | K 2 pi R_c^2 F / nu | Monchaux2009 |
| Theta | (F1 - F2)/(F1 + F2) | Monchaux2009 |
| gamma | (Gamma1 - Gamma2)/(Gamma1 + Gamma2) | Monchaux2009 |
| N | sigma B0^2 L / (rho U) | Bourgoin2002 |
| Pm | nu / eta = nu mu0 sigma | Bourgoin2002 |
