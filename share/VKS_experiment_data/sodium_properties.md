# Sodium properties and operating conditions

Source papers: `Bourgoin2002`, `Monchaux2007`, `Monchaux2009`.

| Quantity | Symbol | Value | Unit | Source / notes |
|---|---|---:|---|---|
| Density | rho | 929 | kg m^-3 | Monchaux2009; Bourgoin2002 uses 930 |
| Dynamic viscosity | mu | 6.9e-4 | Pa s | Monchaux2007, about 120 C |
| Kinematic viscosity | nu | 7.4e-7 | m^2 s^-1 | Monchaux2007 |
| Electrical conductivity | sigma(T) | 108/(6.225+0.0345 T) | S m^-1 | Monchaux2009, Eq. (1), T in C |
| Thermal conductivity | lambda | 85 | W m^-1 K^-1 | Monchaux2007 |
| Specific heat | Cp | 1380 | J kg^-1 K^-1 | Monchaux2007 |
| Magnetic diffusivity | eta | 0.078 | m^2 s^-1 | Monchaux2007 |
| Magnetic Prandtl number | Pm | 1e-5 | - | Monchaux2009 |
| Operating temperature | T_op | 110-160 | deg C | Monchaux2009 |
| Impeller efficiency | K | 0.6 | - | Monchaux2009; 0.7 for opposite rotation direction |
| Maximum impeller frequency | F_max | 27 | Hz | Monchaux2009 |
| Maximum Rm | Rm_max | 49 | - | Monchaux2009 (52 in Ravelet2008) |
| Maximum Re | Re_max | 5e6 | - | Monchaux2009 |

At 120 C, sigma is approximately 1.03e7 S m^-1.
